# 📊 Bank Loan Analysis Dashboard

An end-to-end **Data Analytics** project built using **Power BI, SQL Server, Power Query, DAX, and Excel** to analyze bank loan data and provide actionable business insights through interactive dashboards.

---

## 📌 Project Overview

This project analyzes a bank's loan portfolio to evaluate lending performance, monitor loan quality, identify customer trends, and support data-driven business decisions.

The project follows the complete data analytics workflow:

- Data Collection
- Data Cleaning & Transformation
- SQL Data Analysis
- Power Query
- Data Modeling
- DAX Calculations
- Interactive Dashboard Development
- Business Insights

---

## 🎯 Business Problem

Banks process thousands of loan applications every month. To make informed lending decisions, it is essential to monitor:

- Total Loan Applications
- Total Funded Amount
- Total Amount Received
- Good Loan vs Bad Loan Performance
- Monthly Lending Trends
- Regional Loan Distribution
- Loan Purpose Analysis
- Customer Employment Analysis
- Home Ownership Analysis

This dashboard provides a centralized solution to monitor these KPIs and improve lending decisions.
